## Design Context

### Users
Omarchy desktop users writing contextual Markdown notes alongside their current app, file, or page.

### Brand Personality
Calm, direct, native. Match the installed Omarchy theme.

### Aesthetic Direction
The user chose subtle frost/scale/fade and Omawrite as the reference for readable type and centered writing margins. Preserve theme typography; make the note body larger than the controls. Shortcuts belong in hover hints and the help guide.

### Design Principles
- Center a comfortable writing column on wide windows; retain usable margins in narrow windows.
- Keep text left-aligned inside that column.
- Use native controls and quiet contextual information.
- Snapshot explicitly inserts the source window's current image into the note.
- Preserve the user's working context and notes during updates and verification.
